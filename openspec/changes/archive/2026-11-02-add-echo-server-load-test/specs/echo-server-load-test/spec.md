# Spec Delta

## Purpose
提供基于 Netty 的 TCP echo 服务端压测工具，以可控速率建立大量长连接并周期性发送请求、校验回显，输出连接数、吞吐与延迟统计，用于评估 echo 服务端可承载的最大客户端数。

## ADDED Requirements

### Requirement: 配置与默认值
系统 SHALL 提供 `EchoLoadTestConfig` 配置与 `--key=value` 命令行参数解析，默认目标地址为 `10.10.10.206:19090`，并对非法配置抛出 `IllegalArgumentException`。

#### Scenario: 使用默认配置
- **WHEN** 不传任何参数解析配置
- **THEN** 目标为 `10.10.10.206:19090`，连接数为 `1000`，运行时长为 `60` 秒，报文长度范围为 `16-128`

#### Scenario: 覆盖配置
- **WHEN** 传入 `--host=127.0.0.1 --port=9000 --clients=5000 --duration=0`
- **THEN** 配置中目标为 `127.0.0.1:9000`、连接数为 `5000`、运行模式为一直运行

#### Scenario: 非法参数
- **WHEN** 传入未知参数名，或连接数、最小/最大报文长度、建连速率不大于 0，或最小报文长度大于最大报文长度，或时长、间隔为负数，或端口不在 `1-65535`
- **THEN** 抛出 `IllegalArgumentException`

### Requirement: 爬坡建连
系统 SHALL 按配置的建连速率与最大并发建连数逐步建立连接，直至发起数达到目标连接数；建连失败不重试并计入失败数。

#### Scenario: 全部连接建立
- **WHEN** 对可正常回显的服务端以 `clients=20` 运行
- **THEN** 统计中已建立连接数达到 `20`，建连失败数为 `0`

#### Scenario: 建连失败计数
- **WHEN** 目标端口没有服务监听
- **THEN** 建连失败数等于目标连接数，已建立连接数为 `0`，工具不抛出异常并正常结束

### Requirement: 运行模式
系统 SHALL 支持按时长运行后自动停止，以及时长为 `0` 时一直运行直到调用 `stop()` 或进程收到终止信号。

#### Scenario: 定时运行
- **WHEN** 以 `duration=2` 调用 `run`
- **THEN** 约 2 秒后返回最终报告，所有连接已关闭

#### Scenario: 一直运行并手动停止
- **WHEN** 以 `duration=0` 调用 `start`，等待一段时间后调用 `stop()`
- **THEN** 会话在调用 `stop()` 前持续运行，调用后关闭所有连接并可取得最终报告；重复调用 `stop()` 不抛异常

### Requirement: Ping-pong 请求与回显校验
系统 SHALL 在每个连接上每次发送一个长度在配置范围内（默认 16～128 字节）随机、内容为随机字母数字的字符串，收齐等长回显并逐字节校验后按间隔发送下一次请求；回显内容不一致或回显超时时计数并关闭该连接。

#### Scenario: 随机报文长度与内容
- **WHEN** 以默认配置发送多次请求
- **THEN** 每次请求的长度均在 `16-128` 之间，内容仅包含 `0-9A-Za-z`，且不同请求的长度与内容随机变化

#### Scenario: 正常回显
- **WHEN** 服务端原样回显
- **THEN** 请求完成数持续增长，内容错误数与回显超时数均为 `0`

#### Scenario: 回显内容错误
- **WHEN** 服务端写回与请求不同的字节
- **THEN** 内容错误数大于 `0`，对应连接被关闭

#### Scenario: 回显超时
- **WHEN** 服务端接受连接但不回显
- **THEN** 超过回显超时后回显超时数大于 `0`，对应连接被关闭

### Requirement: 统计输出
系统 SHALL 按配置间隔输出统计行，并在结束时返回 `EchoLoadReport`，包含目标/已发起/当前在线/峰值在线/建连失败/被动断开连接数、请求完成数、QPS、回显超时数、内容错误数、平均与最大延迟、收发字节数。

#### Scenario: 获取运行中快照
- **WHEN** 会话运行中调用 `snapshot()`
- **THEN** 返回当前统计快照，且不影响压测继续运行

#### Scenario: 主动关闭不计入被动断开
- **WHEN** 压测按时长结束并由工具主动关闭连接
- **THEN** 被动断开连接数不因这些关闭而增加
