## Purpose

为 Web 接口建立单一、可预测的异常出口，使参数错误和服务器内部错误都转换为统一响应，同时维持正确的 HTTP 语义并携带链路追踪信息。

## ADDED Requirements

### Requirement: 请求体校验异常转换为统一错误响应
系统 MUST（必须）捕获请求体字段校验异常，返回 HTTP 400；响应 `code` 必须为 `400`，`message` 必须为快速失败产生的字段错误消息，`data` 必须为 `null`。

#### Scenario: 请求体字段校验失败
- **WHEN** 带校验标记的请求体违反字段约束
- **THEN** 系统返回 HTTP 400 和包含首项字段错误消息的统一错误响应

### Requirement: 方法参数校验异常转换为统一错误响应
系统 MUST（必须）捕获控制器方法参数约束产生的校验异常，返回 HTTP 400；响应 `code` 必须为 `400`，`message` 必须包含一项可供调用方理解的约束错误消息。

#### Scenario: 查询参数违反约束
- **WHEN** 查询参数或路径参数违反控制器方法声明的约束
- **THEN** 系统返回 HTTP 400 和包含相应约束错误消息的统一错误响应

### Requirement: Web 参数解析异常转换为统一错误响应
系统 MUST（必须）将缺少必填参数、参数绑定失败以及请求体不可读取等客户端输入错误转换为 HTTP 400 和统一错误响应；响应 `code` 必须为 `400`，且不得向调用方暴露框架堆栈信息。

#### Scenario: 缺少必填参数
- **WHEN** 请求缺少控制器声明的必填参数
- **THEN** 系统返回 HTTP 400 和说明参数错误的统一错误响应

#### Scenario: 请求体无法解析
- **WHEN** 请求体 JSON 语法错误或字段类型无法转换
- **THEN** 系统返回 HTTP 400 和说明请求内容不可解析的统一错误响应

### Requirement: 未预期异常转换为安全的统一错误响应
系统 MUST（必须）兜底捕获未被更具体处理器匹配的异常，记录包含异常堆栈和 `traceId` 的错误日志，并返回 HTTP 500；响应 `code` 必须为 `500`、`message` 必须为不泄露内部实现细节的固定中文提示、`data` 必须为 `null`。

#### Scenario: 发生未预期异常
- **WHEN** 接口处理过程中抛出未被具体异常处理规则覆盖的异常
- **THEN** 系统记录完整错误日志并返回 HTTP 500 和安全的统一错误响应

### Requirement: 所有异常响应携带链路追踪标识
全局异常处理生成的每个统一错误响应 MUST（必须）携带当前请求的 `traceId`，并与 `X-Trace-Id` 响应头一致。

#### Scenario: 参数异常响应的链路追踪标识
- **WHEN** 当前 HTTP 请求因参数错误进入全局异常处理
- **THEN** 错误响应体 `traceId` 与 `X-Trace-Id` 响应头一致

#### Scenario: 服务器异常响应的链路追踪标识
- **WHEN** 当前 HTTP 请求因未预期异常进入全局异常处理
- **THEN** 错误响应体 `traceId` 与 `X-Trace-Id` 响应头一致
