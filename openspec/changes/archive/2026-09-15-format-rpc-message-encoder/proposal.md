## Why

`org.example.simple.rpc` 包内多个类将构造方法、业务方法和控制流压缩为单行，且缺少公共 API、关键字段和复杂处理路径的说明，违反项目 Java 换行、缩进和可读性约定，不利于维护和评审。

## What Changes

- 调整 `org.example.simple.rpc` 包及其子包内全部 Java 源文件的排版：为成员、构造方法、方法注解、控制流和链式调用补全符合项目约定的换行与四空格缩进。
- 为公共 API、对外配置项及不易理解的关键字段、内部处理路径补充中文 Javadoc 或行级注释；不为语义明显的私有实现机械添加重复注释。
- 保持所有编解码逻辑、公开 API、异常类型、配置默认值和消息内容完全不变。

## Capabilities

本变更仅涉及不改变行为的代码格式化，因此不新增或修改行为规范。

## Impact

- 影响范围：`src/main/java/org/example/simple/rpc/` 及其全部子包。
- 不涉及依赖、运行时配置、协议字段、测试契约或外部系统。
