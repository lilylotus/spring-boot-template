# HTTP 客户端配置规范

## Purpose

为 HTTP 调用定义安全且可预测的客户端级配置和单次请求覆盖规则，使 SSL 校验与超时行为能够按环境配置并保持明确优先级。

## Requirements

### Requirement: 默认严格校验 SSL
系统 SHALL 默认校验 HTTPS 服务端证书链和主机名，且仅在调用方显式启用跳过 SSL 校验时同时跳过证书链与主机名校验。

#### Scenario: 默认拒绝不可信证书
- **WHEN** 调用方未启用跳过 SSL 校验且 HTTPS 服务端证书不可信或主机名不匹配
- **THEN** 系统终止请求并抛出保留 TLS 原因的客户端异常

#### Scenario: 显式跳过 SSL 校验
- **WHEN** 调用方在静态全局客户端配置中显式启用跳过 SSL 校验
- **THEN** 后续静态请求允许连接证书链不可信或主机名不匹配的 HTTPS 服务端

### Requirement: 支持客户端级分阶段默认超时
系统 SHALL 要求静态全局客户端的连接超时和响应超时均为大于零的有限时长，
并 SHALL 在默认配置中将两者均设置为 3 秒。连接超时 SHALL 约束连接建立和连接池获取阶段，
响应超时 SHALL 约束响应等待和套接字读取阶段。

#### Scenario: 使用默认分阶段超时
- **WHEN** 调用方发送请求且未指定单次请求超时
- **THEN** 系统使用 3 秒默认连接超时和 3 秒默认响应超时

#### Scenario: 独立应用连接和响应超时
- **WHEN** 调用方配置不同的连接超时和响应超时
- **THEN** 系统将连接超时仅应用于连接建立和连接池获取，并将响应超时仅应用于响应等待和套接字读取

#### Scenario: 拒绝非法默认超时
- **WHEN** 调用方将连接超时或响应超时配置为零、负数、空值或超出底层客户端可表达范围的时长
- **THEN** 系统在替换静态全局客户端配置前拒绝该配置，并保持原配置继续生效

#### Scenario: 原子替换全局配置
- **WHEN** 调用方在存在请求并发执行时设置新的合法全局配置
- **THEN** 系统等待已有请求安全完成后原子替换共享客户端，后续请求使用新配置且不会访问已关闭连接池

### Requirement: 支持单次请求超时覆盖
系统 SHALL 允许调用方为单次请求指定大于零的有限响应超时，
并 SHALL 仅对该次请求覆盖客户端级默认响应超时。

#### Scenario: 单次请求覆盖默认超时
- **WHEN** 请求同时存在客户端级默认超时和合法的单次请求超时
- **THEN** 系统对该请求的响应等待和套接字读取阶段使用单次请求超时，不修改全局连接超时或响应超时

#### Scenario: 覆盖不影响后续请求
- **WHEN** 一个请求使用单次请求超时后，调用方发送未指定超时的后续请求
- **THEN** 后续请求继续使用客户端级默认响应超时

#### Scenario: 请求超时
- **WHEN** 响应等待或套接字读取阶段超过该请求最终生效的响应超时
- **THEN** 系统中止请求并抛出可识别的超时异常

#### Scenario: 拒绝非法单次超时
- **WHEN** 调用方配置零、负数或超出底层客户端可表达范围的单次请求超时
- **THEN** 系统在发送网络请求前拒绝该请求

### Requirement: 提供生产级共享连接池配置
系统 SHALL 为静态 HTTP 客户端提供有界、可配置且可回收的共享连接池。默认总连接上限 SHALL 为 200，
单个目标路由连接上限 SHALL 为 50，连接最长存活时间 SHALL 为 5 分钟，连接空闲 5 秒后 SHALL 在复用前校验，
并 SHALL 回收过期连接和空闲超过 30 秒的连接。

#### Scenario: 使用生产推荐默认值
- **WHEN** 调用方使用默认客户端配置
- **THEN** 系统使用总连接 200、单路由连接 50、连接存活 5 分钟、空闲校验 5 秒和空闲回收 30 秒的共享连接池

#### Scenario: 严格限制连接容量
- **WHEN** 同一时刻的请求数量超过配置的总连接上限或单路由连接上限
- **THEN** 系统不创建超出对应上限的连接，等待连接的请求受最终生效的连接超时约束

#### Scenario: 复用有效连接
- **WHEN** 连接未超过存活期且空闲状态校验通过
- **THEN** 系统优先复用最近使用的可用连接，而不是为每次请求创建新连接

#### Scenario: 淘汰过期或空闲连接
- **WHEN** 连接超过配置的存活期或空闲时间超过回收阈值
- **THEN** 系统停止复用并释放该连接，且关闭或重配置客户端时停止对应的连接回收资源

#### Scenario: 覆盖连接池配置
- **WHEN** 调用方提供合法的总连接上限、单路由连接上限、连接存活期、空闲校验时长和空闲回收时长
- **THEN** 系统为后续静态请求创建使用这些值的新共享连接池

#### Scenario: 拒绝非法连接池配置
- **WHEN** 调用方配置非正连接上限、单路由上限大于总上限、空时长、负时长、零时长或底层客户端无法表达的时长
- **THEN** 系统在替换现有共享客户端前拒绝该配置，并保持原客户端继续可用

### Requirement: 提供已初始化的默认 JSON 映射器
系统 SHALL 为默认客户端配置创建专用且已初始化的 `ObjectMapper`，反序列化 SHALL 忽略目标类型中不存在的 JSON 字段，
序列化 SHALL 省略值为 `null` 的属性，并 SHALL 使用 ISO-8601 字符串序列化和反序列化 Java 时间类型。
调用方显式注入自定义映射器时，系统 SHALL 保留其配置。

#### Scenario: 忽略未知响应字段
- **WHEN** JSON 响应包含目标 Java 类型未声明的字段
- **THEN** 系统忽略该字段并完成目标对象转换

#### Scenario: 省略空值请求属性
- **WHEN** 默认映射器序列化的请求对象包含值为 `null` 的属性
- **THEN** 生成的 JSON 不包含该属性

#### Scenario: 处理 Java 时间类型
- **WHEN** 默认映射器序列化或反序列化受支持的 Java 时间类型
- **THEN** 系统使用对应的 ISO-8601 字符串而不是数字时间戳

#### Scenario: 使用自定义映射器
- **WHEN** 调用方在客户端配置中显式提供自定义 `ObjectMapper`
- **THEN** 系统直接使用该映射器且不覆盖调用方配置

### Requirement: 客户端资源可管理
系统 SHALL 在所有静态请求之间复用进程级连接资源，并 SHALL 提供幂等的静态关闭能力；关闭后不得接受新请求，直到调用方重新设置合法全局配置。

#### Scenario: 关闭客户端
- **WHEN** 调用方调用静态关闭方法一次或多次
- **THEN** 系统等待已有请求完成后释放共享连接资源，且重复关闭不产生错误

#### Scenario: 关闭后发送请求
- **WHEN** 调用方在静态全局客户端关闭后且尚未重新配置时尝试发送请求
- **THEN** 系统在发送网络请求前抛出客户端状态异常

#### Scenario: 关闭后重新配置
- **WHEN** 调用方在静态全局客户端关闭后设置合法全局配置
- **THEN** 系统创建新的共享客户端，后续静态请求恢复可用
