# snowflake-id-generation Specification

## Purpose

为单机和分布式部署提供无需中心存储的长整型 ID 生成能力，在明确分配节点标识的前提下保证线程安全、唯一性、趋势递增和可诊断失败。

## Requirements

### Requirement: 一次性且不可变的节点初始化
工具 SHALL 支持发号前显式配置数据中心编号和工作节点编号，两个编号的有效范围均为 0 到 31。未配置时首次发号 SHALL 自动以节点 `(0, 0)` 初始化。相同节点参数的重复初始化 SHALL 幂等成功，不同节点参数的重复初始化 MUST 被拒绝。工具 MUST NOT 根据 IP、网卡地址、进程号或随机数自动推断节点编号。

#### Scenario: 使用有效节点参数初始化
- **WHEN** 调用方以有效的数据中心编号和工作节点编号首次初始化
- **THEN** 工具保存该节点配置并允许生成 ID

#### Scenario: 拒绝越界节点参数
- **WHEN** 数据中心编号或工作节点编号小于 0 或大于 31
- **THEN** 工具抛出参数异常且不完成初始化

#### Scenario: 相同配置重复初始化
- **WHEN** 工具已初始化且调用方再次传入相同节点参数
- **THEN** 初始化幂等完成且后续 ID 使用原节点配置

#### Scenario: 拒绝冲突配置
- **WHEN** 工具已初始化且调用方传入不同节点参数
- **THEN** 工具抛出状态异常且不改变原节点配置

#### Scenario: 未初始化生成 ID
- **WHEN** 调用方在初始化前请求生成 ID
- **THEN** 工具使用数据中心编号 0 和工作节点编号 0 自动初始化并返回 ID

#### Scenario: 并发首次生成 ID
- **WHEN** 多个线程在未初始化时同时请求生成 ID
- **THEN** 工具只初始化一个共享生成器，所有成功返回的 ID 均不重复且使用默认节点组合

#### Scenario: 显式初始化与默认初始化竞争
- **WHEN** 显式初始化与首次发号并发执行
- **THEN** 最先完成初始化的节点配置固定生效；发号使用该配置，后续冲突显式初始化被拒绝且不替换生成器

### Requirement: 标准雪花位布局
工具 SHALL 返回正数 `long` ID，并 SHALL 使用从高到低依次为 1 个符号位、41 位相对毫秒时间戳、5 位数据中心编号、5 位工作节点编号和 12 位序列号的布局。时间戳 SHALL 相对于固定纪元 `2025-01-01T00:00:00Z` 计算。

#### Scenario: ID 可按位解析
- **WHEN** 调用方使用已知节点配置生成 ID
- **THEN** 从 ID 对应位段解析出的节点编号与初始化参数一致，时间戳不早于固定纪元，序列号位于 0 到 4095

#### Scenario: 时间戳超出可表示范围
- **WHEN** 当前时间早于固定纪元或相对时间超过 41 位最大值
- **THEN** 工具抛出状态异常且不生成截断或负数 ID

### Requirement: 线程安全、唯一且趋势递增
工具 SHALL 在同一 JVM 和固定节点配置下安全处理并发调用，所有成功返回的 ID MUST 唯一。按照生成器实际受理顺序，后生成的 ID MUST 大于先生成的 ID。

#### Scenario: 多线程并发生成
- **WHEN** 多个线程同时请求大量 ID
- **THEN** 每次调用均返回正数 ID，且结果集合中不存在重复值

#### Scenario: 连续生成趋势递增
- **WHEN** 单个线程连续请求多个 ID
- **THEN** 每个后续 ID 均严格大于前一个 ID

### Requirement: 毫秒内序列与容量控制
工具 SHALL 在同一毫秒内使用 12 位序列生成至多 4096 个 ID。序列用尽时工具 MUST 等待时钟进入下一毫秒并将序列重新从 0 开始，MUST NOT 回绕生成重复 ID。

#### Scenario: 同毫秒生成多个 ID
- **WHEN** 同一毫秒内连续生成多个 ID
- **THEN** 时间戳和节点位保持不变，序列号逐一递增且 ID 不重复

#### Scenario: 同毫秒序列耗尽
- **WHEN** 同一毫秒已生成 4096 个 ID 并再次请求 ID
- **THEN** 工具等待下一毫秒后返回具有新时间戳且序列号为 0 的 ID

### Requirement: 时钟回拨保护
工具 SHALL 检测当前时钟早于最近成功生成 ID 的时间戳。回拨不超过 5 毫秒时，工具 SHALL 有限等待时钟恢复；回拨超过 5 毫秒时，工具 MUST 快速失败并报告回拨毫秒数。等待期间线程被中断时，工具 MUST 保留中断状态并失败。

#### Scenario: 轻微时钟回拨后恢复
- **WHEN** 时钟回拨不超过 5 毫秒并在等待期间恢复到最近时间戳
- **THEN** 工具继续生成大于已有 ID 的唯一 ID

#### Scenario: 严重时钟回拨
- **WHEN** 时钟回拨超过 5 毫秒
- **THEN** 工具抛出状态异常且异常消息包含回拨毫秒数

#### Scenario: 等待时钟期间被中断
- **WHEN** 线程在等待下一毫秒或等待轻微回拨恢复时被中断
- **THEN** 工具保留线程中断状态并抛出状态异常
