# 常用数据结构使用说明

`org.example.simple.algorithm` 包提供常用数据结构的规范实现，仅依赖 JDK：

- 线性结构：`DoublyLinkedList`（双向链表）、`ArrayStack`（栈）、`CircularArrayQueue`（队列）、`CircularArrayDeque`（双端队列）。
- 有序键值结构：统一接口 `OrderedMap`，实现类为 `BinarySearchTree`（二叉搜索树）、`RedBlackTree`（红黑树）、`AvlTree`（AVL 树）、`BTree`（B 树）、`BPlusTree`（B+ 树）。

类名带有实现方式，避免与 `java.util.LinkedList`、`Stack`、`ArrayDeque` 等混淆。

## 线性结构

| 结构 | 实现 | 主要操作 | 复杂度 | 允许 null |
| --- | --- | --- | --- | --- |
| `DoublyLinkedList` | 双向节点 + 头尾引用 | `addFirst`/`addLast`/`removeFirst`/`removeLast`/`getFirst`/`getLast` | O(1) | 是 |
| | | `add(index, e)`/`get`/`set`/`removeAt`/`indexOf`/`remove(Object)`/`reverse` | O(n) | |
| `ArrayStack` | 动态数组 | `push`/`pop`/`peek` | 均摊 O(1) | 否 |
| `CircularArrayQueue` | 循环数组 | `enqueue`/`dequeue`/`peek` | 均摊 O(1) | 否 |
| `CircularArrayDeque` | 循环数组 | `addFirst`/`addLast`/`removeFirst`/`removeLast`/`peekFirst`/`peekLast` | 均摊 O(1) | 否 |

约定：

- 空结构上取出或查看元素抛出 `NoSuchElementException`；下标越界抛出 `IndexOutOfBoundsException`。
- 栈、队列、双端队列放入 `null` 抛出 `NullPointerException`。
- 数组结构满时容量翻倍，元素降到容量 1/4 时减半（不低于默认容量 8）；构造时可指定初始容量，非正数抛出 `IllegalArgumentException`。
- 链表按下标删除的方法名为 `removeAt(int)`，避免与 `remove(Object)` 在 `Integer` 元素上产生重载歧义。
- 均提供 `size`、`isEmpty`、`clear`、`toList`；迭代器为 fail-fast，栈按出栈顺序、队列按出队顺序遍历。

```java
DoublyLinkedList<String> list = new DoublyLinkedList<>();
list.addLast("b");
list.addFirst("a");
list.add(2, "c");                 // [a, b, c]
list.reverse();                   // [c, b, a]
list.removeAt(1);                 // 返回 b

ArrayStack<Character> stack = new ArrayStack<>();
stack.push('(');
stack.pop();                      // '('

CircularArrayQueue<Integer> queue = new CircularArrayQueue<>();
queue.enqueue(1);
queue.enqueue(2);
queue.dequeue();                  // 1

CircularArrayDeque<Integer> deque = new CircularArrayDeque<>();
deque.addFirst(1);
deque.addLast(2);
deque.removeLast();               // 2
```

## 有序键值结构 `OrderedMap`

接口方法：`put`、`get`、`containsKey`、`remove`、`size`、`isEmpty`、`clear`、`minKey`、`maxKey`、`floorKey`、`ceilingKey`、`keys`（升序）、`range(from, to)`（闭区间）、`forEach`（升序）、`height`，并实现 `Iterable<Map.Entry<K, V>>`（按键升序）。

约定：

- 键按自然顺序（`Comparable`）比较，不支持 `Comparator`；键相等仅依据 `compareTo`。
- 键不允许为 `null`（抛出 `NullPointerException`）；值允许为 `null`，需用 `containsKey` 区分“不存在”与“值为 null”。
- `put` 返回旧值，`remove` 返回被删值，键不存在时均返回 `null`。
- 空结构调用 `minKey`/`maxKey` 抛出 `NoSuchElementException`；`floorKey`/`ceilingKey` 无结果时返回 `null`；`range` 的 `from > to` 时返回空列表。
- 迭代器为 fail-fast：迭代期间插入或删除键抛出 `ConcurrentModificationException`，覆盖已有键的值不受影响；返回的 `Map.Entry` 为不可变快照。
- 均非线程安全。

```java
OrderedMap<Integer, String> map = new RedBlackTree<>();
map.put(30, "c");
map.put(10, "a");
map.put(20, "b");
map.floorKey(25);                 // 20
map.ceilingKey(25);               // 30
map.range(10, 20);                // [10=a, 20=b]
map.keys();                       // [10, 20, 30]

OrderedMap<Long, String> index = new BPlusTree<>(64);   // 阶数 64
OrderedMap<String, Integer> btree = new BTree<>(4);     // 最小度数 4
```

### 实现对比

| 实现 | 查找/插入/删除 | 树高 | 特点与适用场景 |
| --- | --- | --- | --- |
| `BinarySearchTree` | 平均 O(log n)，最坏 O(n) | 最坏 n | 不自平衡；有序插入退化为链表。全迭代实现，不会栈溢出。用于教学或键足够随机的场景 |
| `RedBlackTree` | O(log n) | ≤ 2·log₂(n+1) | 平衡较宽松，插入至多 2 次、删除至多 3 次旋转；写多读多的通用场景（`TreeMap` 同款） |
| `AvlTree` | O(log n) | ≤ 约 1.44·log₂(n+2) | 严格平衡，查找更快、修改旋转更多；读多写少的场景 |
| `BTree` | O(t·log_t n) | O(log_t n) | 多路平衡，键值存于所有节点；默认最小度数 `t = 3`，要求 `t ≥ 2` |
| `BPlusTree` | O(m·log_m n) | O(log_m n) | 数据只在叶子，叶子链表相连，范围查询 O(log n + k)；默认阶数 `m = 4`，要求 `m ≥ 3`。数据库索引的常用结构 |

选型建议：通用有序映射优先 `RedBlackTree`；查询远多于修改时用 `AvlTree`；需要频繁范围扫描或演示索引结构时用 `BPlusTree`；`BTree` 用于对比演示多路平衡树；`BinarySearchTree` 仅用于教学或对比退化现象。生产环境请优先使用 JDK 的 `java.util.TreeMap`。

B 树与 B+ 树为纯内存实现，节点大小以键数度量，不涉及磁盘页管理与持久化。

## 不在范围内

- 不实现 `java.util.List`、`Deque`、`NavigableMap` 等 JDK 集合接口；需要互操作时通过 `toList`、`keys`、`range` 转换。
- 不支持自定义 `Comparator` 与 `null` 键。
- 不提供线程安全、序列化与持久化。
